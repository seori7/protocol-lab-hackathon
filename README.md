# Protocol Lab 🔬

**Protocol Lab (Desktop Edition)** — это локальное настольное приложение для реверс-инжиниринга и визуального анализа неизвестных бинарных сетевых протоколов.

Инструмент решает классическую проблему ИБ-аналитиков: автоматизирует процесс поиска паттернов в «сырых» дампах трафика, объединяя понимание сетевых сессий (как в Wireshark) и гибкость продвинутого Hex-редактора (как в 010 Editor).

---

## 🌟 Ключевые возможности (Features)

*   **Умная ингестия (TCP Reassembly):** Под капотом работает движок на базе `Scapy`, который потоково (без перегрузки RAM) читает `.pcap/.pcapng` файлы, склеивает разрозненные пакеты в сессии, сортирует их по Sequence Number и автоматически удаляет дубликаты (retransmissions).
*   **Сверхбыстрый интерактивный HexViewer:** Сетка из тысяч байт отрендерена на React с использованием *Event Delegation* и строгой мемоизации. Не тормозит при выделении огромных массивов данных.
*   **Движок Интерпретации Правил:** Возможность визуально выделить байты и задать им тип (uint32, float, ascii и т.д.). Сервер мгновенно применяет это правило ко всему корпусу пакетов, находя совпадения и контрпримеры.
*   **Конструктор произвольных гипотез (Scripting):** Вы можете выбрать конкретные пакеты (чекбоксами) и написать произвольный код (JavaScript), чтобы проверить сложную зависимость между пакетами (например, *«совпадает ли 4-й байт пакета А с 8-м байтом пакета Б»*).
*   **Математическая Эвристика:** Автоматический расчет Энтропии Шеннона для визуального отделения зашифрованных/сжатых данных от структурных заголовков. Визуальный Diff (сравнение) пакетов.
*   **Отчуждаемость и Экспорт:** Сохранение состояния всего исследования в единый файл формата `.madrigal` (включая заметки к пакетам и правила) для передачи коллегам.

## 🏗 Архитектура и Технологический стек

*   **Desktop Shell:** `PyWebView` (Нативное графическое окно ОС).
*   **Frontend:** React 18, TypeScript, Tailwind CSS, Vite.
*   **Backend:** Python 3.10+, FastAPI (REST API).
*   **Network Engine:** `Scapy` (Потоковый парсинг без утечек памяти).

*Примечание: Система спроектирована по принципу API-First. Фронтенд полностью изолирован от бэкенда, что позволяет в будущем легко переписать модуль парсинга на компилируемые языки (C++/Rust) для работы с дампами >10 ГБ.*

## 🚀 Запуск проекта (Инструкция для жюри)

Приложение разработано и протестировано с учетом требований к **Linux x86-64**. Для вашего удобства мы подготовили bash-скрипт, который автоматически установит необходимые системные графические библиотеки (GTK/WebKit2), настроит Python и запустит приложение.

### Вариант 1: Быстрый запуск на Linux (Ubuntu/Debian) — Рекомендуемый

1. Откройте терминал в корневой папке проекта.
2. Выдайте права на исполнение скрипту запуска:
   ```bash
   chmod +x run.sh
3. Запустите скрипт (может потребоваться пароль sudo для установки системных зависимостей окна pywebview и tshark):
Bash

./run.sh
Скрипт соберет проект и автоматически откроет нативное десктопное окно Protocol Lab.

### Вариант 2: Ручной запуск (Windows / Linux)
Если вы хотите запустить проект вручную:

Подготовка фронтенда:
Bash

cd frontend
npm install
npm run build
cd ..
Подготовка бэкенда:
Bash

python -m venv venv
source venv/bin/activate  # Для Windows: .\venv\Scripts\activate
pip install -r backend/requirements.txt
pip install pywebview
Запуск окна:
Bash

python start_app.py
🧪 Сценарий тестирования (Как проверить функционал)
Чтобы увидеть всю мощь инструмента, выполните следующие шаги:

Нажмите «Загрузить PCAP» в левом верхнем углу и выберите тестовый дамп.
Слева появится список очищенных пакетов. Выберите несколько пакетов галочками.
Нажмите на пакет, чтобы открыть его в Hex Viewer. Выделите зажатой левой кнопкой мыши 4 байта.
В правой панели задайте тип данных (например, uint32) и нажмите «Создать правило».
Нажмите «Проверить правила» — вы увидите, как сервер найдет это значение в других пакетах или выдаст ошибку (если пакет слишком короткий).
В правой панели переключитесь на вкладку «Скрипты (Гипотезы)». Напишите свой JavaScript-код для сравнения выбранных ранее пакетов и нажмите «Проверить гипотезу».
